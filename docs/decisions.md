## 架构分层

```
交互层     FastAPI · SSE 流式 · 对话页 · 运营工作台 · 链路可视化
   ↓
编排层     LangGraph Supervisor → intent → route → specialists
   ↓
能力层     RAG · 工具 · 记忆 · 兜底 · 模型接入 · 可观测
   ↓
数据层     Milvus · MySQL/SQLAlchemy · Docker Compose
```

| 要补的 | 为什么 | 面试怎么讲 |

| 限流 / 熔断 / 模型降级 | 上游模型会超时、限流、宕机,课程只做了"直连上游" | "网关层做了令牌桶限流和熔断,模型不可用时降级到备用供应商" |
